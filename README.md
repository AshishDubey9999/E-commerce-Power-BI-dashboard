# 🛒 E-Commerce Sales Analysis Dashboard | Power BI

An interactive **E-Commerce Sales Analysis Dashboard** built using Microsoft Power BI to explore sales performance, profitability, product categories, and business trends through data visualization.

## 📌 Project Overview

This project transforms e-commerce sales data into an interactive dashboard that helps users understand business performance, compare product categories, and analyze sales and profit trends.

The report contains three pages, each designed to provide a different business perspective.

## 🎯 Project Objectives

- Analyze overall sales, profit, and quantity.
- Compare sales and profitability across product categories.
- Identify top-performing products and sub-categories.
- Explore monthly sales and profit trends.
- Analyze sales distribution across payment modes and regions.
- Enable interactive exploration through slicers and filters.

## 📊 Dashboard Pages

### 1. Executive Sales Overview
- Key performance indicator (KPI) cards.
- State-wise sales and profit analysis.
- Category and sub-category comparisons.
- Interactive report filters.

### 2. Product & Category Performance Analysis
- Product-level performance table.
- Category-wise sales, profit, and quantity analysis.
- Top sub-category sales comparison.
- Sales distribution and profitability analysis.

### 3. Sales Trends & Business Insights
- Monthly sales and profit trends.
- Sales versus profit analysis.
- Payment-mode sales distribution.
- Decomposition tree for exploring sales performance.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and visualization
- **DAX** — Measures and calculations
- **Power Query** — Data transformation, where applicable
- **Data Modeling** — Relationships between report tables

## ✨ Key Features

- Interactive slicers and filters.
- Multiple chart types for business analysis.
- KPI cards for performance monitoring.
- Product, category, and regional analysis.
- Consistent visual theme across three report pages.

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Install or open Microsoft Power BI Desktop.
3. Open the downloaded report.
4. Explore the dashboard pages and interact with the available slicers.
5. If prompted, configure the dataset source or refresh the data as required.
